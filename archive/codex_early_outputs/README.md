# Early Codex work — preserved history

This archive preserves earlier **Assembly Line Heart 47–67 s** sample films (v1/v2), their scene/render source, timings, method notes, QA stills and unique delivery records previously living only in the Codex chat workspace. These are historical drafts; Hon subsequently changed the visual/story direction. They are not the current prototype or a final scene selection.

- Current motion source: `../../wip/codex/platformer_motion_v2/`.
- Original relative chat-workspace paths are preserved under `outputs/` and `work/`.
- Every copied file is verified by SHA-256 in `import-manifest.json`.
- ZIPs with old MP3/FLAC excerpts are named `*_without_audio.zip`; every remaining member was hash-verified. Loose old song audio, dependencies and caches were not imported. Existing movies keep their original soundtracks for historical review.
- Byte-identical material already in the project is listed in `../../wip/codex/repository_cleanup_v1/codex_workspace_unique.json` rather than copied again.
